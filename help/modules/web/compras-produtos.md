# Produtos

## O que esta funcionalidade faz

Mantem o catalogo de produtos usados nos pedidos de compra, com busca, categoria e unidade.

## Quando usar

- Ao cadastrar novo item de compras.
- Ao corrigir dados de um produto existente.
- Ao preparar a base para solicitacoes futuras.

## Passo a passo de uso

1. Acesse ` /dashboard/compras/cadastros/produtos `.
2. Busque o produto desejado ou abra o formulario.
3. Informe nome, descricao, categoria e unidade.
4. Salve e valide se o item aparece na lista.

## Campos e elementos da tela

| Campo | Explicacao |
| --- | --- |
| Nome | Identificacao principal do item |
| Descricao | Detalhes tecnicos ou operacionais |
| Categoria | Agrupamento do produto |
| Unidade | Unidade de medida usada no pedido |

- Manter unidade coerente com o processo de compra.
