# Manutenções

## O que esta funcionalidade faz

Controla registros de manutencao da frota com veiculo, data e descricao do servico.

## Quando usar

- Ao abrir manutencao programada ou corretiva.
- Para consultar historico de servicos.
- Para acompanhar proximas intervencoes.

## Passo a passo de uso

1. Acesse ` /dashboard/fleet/maintenance `.
2. Escolha o veiculo.
3. Informe a descricao do servico e os dados da manutencao.
4. Salve para registrar o historico.

## Campos e elementos da tela

| Campo | Explicacao |
| --- | --- |
| Veiculo | Item que recebera o servico |
| Data | Momento da manutencao |
| Descricao | O que foi executado ou precisa ser feito |

- Registrar manutencao corretiva assim que ela ocorrer.
