# Dashboard de Frotas

## O que esta funcionalidade faz

Resume status da frota, manutencoes ativas e proximas manutencoes.

## Quando usar

- Para acompanhar disponibilidade dos veiculos.
- Para enxergar gargalos de manutencao.
- Para priorizar liberacao ou intervencao.

## Passo a passo de uso

1. Abra ` /dashboard/fleet/metrics `.
2. Revise totais, disponiveis, em uso e em manutencao.
3. Consulte a lista de proximas manutencoes.

## Campos e elementos da tela

| Elemento | Explicacao |
| --- | --- |
| Total da frota | Quantidade geral de veiculos |
| Disponiveis / em uso / manutencao | Distribuicao operacional do status |
| Proximas manutencoes | Lista de alertas futuros |
