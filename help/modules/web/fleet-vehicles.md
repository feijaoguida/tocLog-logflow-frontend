# Veículos

## O que esta funcionalidade faz

Lista a frota interna e permite entrar no detalhe de cada veiculo.

## Quando usar

- Para consultar status da frota.
- Para localizar um veiculo por placa ou modelo.
- Para abrir o detalhe do ativo.

## Passo a passo de uso

1. Acesse ` /dashboard/fleet `.
2. Use a busca por placa ou modelo.
3. Revise a listagem e abra o detalhe quando necessario.

## Campos e elementos da tela

| Elemento | Explicacao |
| --- | --- |
| Busca | Localiza veiculos por identificadores principais |
| Lista de veiculos | Resume os ativos da frota |
| Detalhe | Abre informacoes complementares do item |

## Dicas de uso

- Prefira buscar pela placa quando o modelo for repetido.
- Use o detalhe para validar contexto antes de agir.

## Boas praticas

- Manter cadastro de frota atualizado.
- Validar status do veiculo antes de vinculacoes operacionais.
