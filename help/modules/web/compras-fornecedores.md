# Fornecedores

## O que esta funcionalidade faz

Mantem a base de fornecedores com identificacao, CNPJ, email e telefone.

## Quando usar

- Ao homologar um fornecedor para compras.
- Ao atualizar contato comercial.
- Ao preparar a base para cotacoes futuras.

## Passo a passo de uso

1. Abra ` /dashboard/compras/cadastros/fornecedores `.
2. Use a busca para localizar um fornecedor ou abrir cadastro novo.
3. Informe nome, CNPJ, email e telefone.
4. Salve e confirme a disponibilidade do registro para cotacoes.

## Campos e elementos da tela

| Campo | Explicacao |
| --- | --- |
| Nome | Razao ou nome comercial |
| CNPJ | Documento principal do fornecedor |
| Email | Canal de contato |
| Telefone | Apoio operacional e comercial |
