# Rastreamento

## O que esta funcionalidade faz

Concentra o acompanhamento de viagens e checkpoints da frota externa.

## Quando usar

- Para monitorar progresso de uma viagem.
- Para verificar posicao e eventos de rota.
- Para acompanhar entregas em andamento.

## Passo a passo de uso

1. Abra ` /dashboard/external-fleet/tracking `.
2. Selecione a viagem ou contexto desejado.
3. Acompanhe os checkpoints e a evolucao da rota.

## Campos e elementos da tela

| Elemento | Explicacao |
| --- | --- |
| Mapa / rota | Visual de acompanhamento geografico |
| Checkpoints | Pontos registrados ao longo da viagem |
| Status da viagem | Situacao operacional atual |

## Dicas de uso

- Use a tela como acompanhamento, nao como fonte unica de confirmacao de entrega.
- Cruce status com contato operacional quando surgir divergencia.

## Pendente de validacao

- A rota existe no projeto, mas o fluxo completo de rastreamento precisa de validacao manual com dados reais de viagem e mapa.
