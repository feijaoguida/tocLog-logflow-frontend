# Design System

## O que esta funcionalidade faz

Serve como referencia viva do padrao visual adotado pelo frontend web do LogFlow2.

## Quando usar

- Antes de criar ou refatorar uma tela.
- Ao validar se uma pagina nova seguiu o padrao oficial.
- Para alinhar tipografia, espacamento, tokens e composicoes.

## Passo a passo de uso

1. Abra ` /dashboard/cadastros/design-system `.
2. Revise tipografia, componentes-base e composicoes recomendadas.
3. Compare a funcionalidade que sera alterada com o padrao vivo.
4. Ajuste o frontend antes de considerar a tarefa concluida.

## Campos e elementos da tela

| Elemento | Explicacao |
| --- | --- |
| Tipografia | Escala oficial de titulos, corpo e apoio |
| Componentes-base | Inputs, selects, textareas, cards e organizacao |
| Composicoes | Estruturas recomendadas para telas administrativas e operacionais |

## Dicas de uso

- Use esta pagina junto com `docs/standards/design-system.md`.
- Valide se a tela nova reutilizou classes e tokens oficiais.

## Erros ou duvidas comuns

- `A tela ficou boa mas diferente das outras`: comparar com a pagina viva antes de aprovar o layout.
- `Nao sei qual cabecalho usar`: verificar se o fluxo pede hero completo ou header compacto `Menu > Funcao`.

## Boas praticas

- Atualizar a pagina viva quando um novo padrao virar regra.
- Evitar variacoes locais de espacamento sem justificativa.
