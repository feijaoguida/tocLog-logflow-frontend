# Paletes

## O que esta funcionalidade faz

Controla movimentacao de paletes com origem, destino e observacoes.

## Quando usar

- Para registrar transferencia de paletes.
- Para acompanhar circulacao do estoque operacional.
- Para auditar movimentacoes logisticas.

## Passo a passo de uso

1. Abra ` /dashboard/logistics/pallets `.
2. Localize o item desejado.
3. Inicie a movimentacao e informe origem, destino e observacao.
4. Salve e valide o historico atualizado.

## Campos e elementos da tela

| Campo | Explicacao |
| --- | --- |
| Origem | Local atual do palete |
| Destino | Proximo ponto logístico |
| Observacao | Contexto adicional da transferencia |

- Registre a observacao quando houver condicao especial de transporte.
- Valide origem e destino antes de confirmar.

## Boas praticas

- Manter rastreabilidade de cada transferencia.
- Evitar movimentacoes sem justificativa clara.
