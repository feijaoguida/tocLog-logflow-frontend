# Patrimônio

## O que esta funcionalidade faz

Permite cadastrar ativos patrimoniais e registrar transferencias entre contextos organizacionais.

## Quando usar

- Ao incluir um novo ativo.
- Ao transferir patrimonio entre areas.
- Para consultar o inventario patrimonial.

## Passo a passo de uso

1. Acesse ` /dashboard/logistics/assets `.
2. Cadastre o ativo ou abra a acao de movimentacao.
3. Informe tipo, local e observacoes da transferencia.
4. Salve para atualizar o inventario.

## Campos e elementos da tela

| Campo | Explicacao |
| --- | --- |
| Nome do ativo | Identificacao principal do bem |
| Tipo / local | Contexto estrutural do patrimonio |
| Observacao | Motivo ou detalhe da transferencia |
