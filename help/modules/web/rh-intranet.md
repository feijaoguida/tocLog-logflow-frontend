# Intranet

## O que esta funcionalidade faz

Entrega a home de RH com feed interno, perfil resumido, stories, widgets de apoio e compositores de comunicacao.

## Quando usar

- Para acompanhar novidades internas.
- Para publicar comunicados ou interagir com o feed.
- Para acessar atalhos de RH a partir de um ponto central.

## Passo a passo de uso

1. Acesse ` /dashboard/rh `.
2. Consulte perfil, stories e widgets laterais.
3. Use o composer para publicar avisos quando tiver permissao.
4. Interaja com posts, comentarios e destaques internos.

## Campos e elementos da tela

| Elemento | Explicacao |
| --- | --- |
| Perfil | Mostra identidade do usuario e contexto resumido |
| Feed | Lista posts e interacoes da intranet |
| Composer | Permite criar comunicados e conteudos |
| Widgets | Acesso rapido a FAQ, suporte e informacoes de apoio |

## Dicas de uso

- Use a intranet como porta de entrada de comunicacao do modulo.
- Mantenha postagens objetivas e operacionais.

## Erros ou duvidas comuns

- `Nao consigo publicar`: confirmar permissao e estado do composer.
- `O feed esta vazio`: validar se existem posts cadastrados no backend.

## Boas praticas

- Publicar mensagens com contexto e objetivo claros.
- Separar avisos urgentes de conteudos informativos de rotina.
