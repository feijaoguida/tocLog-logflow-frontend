# Gestão de Salas

## O que esta funcionalidade faz

Permite cadastrar e manter salas de reuniao, recursos e dados usados pelas reservas.

## Quando usar

- Ao criar uma nova sala disponivel para agendamento.
- Ao atualizar capacidade, nome ou recursos.
- Ao revisar disponibilidade estrutural do espaco.

## Passo a passo de uso

1. Abra ` /dashboard/rh/salas `.
2. Inicie o cadastro ou edite uma sala existente.
3. Informe nome, capacidade e recursos aplicaveis.
4. Salve para liberar a sala na agenda.

## Campos e elementos da tela

| Campo | Explicacao |
| --- | --- |
| Nome | Identificacao da sala |
| Capacidade | Quantidade aproximada de pessoas |
| Recursos | Itens como TV, projetor ou estrutura adicional |
| Busca de recurso | Campo para localizar ou criar itens de apoio |

## Dicas de uso

- Padronize nomes de salas por andar, unidade ou finalidade.
- Revise recursos antes de liberar a sala para reservas.

## Erros ou duvidas comuns

- `Nao encontro o recurso`: digite parte do nome e valide se ele ja existe.
- `A sala nao aparece na agenda`: confirmar se o cadastro foi salvo corretamente.

## Boas praticas

- Manter capacidade realista para evitar reservas inadequadas.
- Atualizar recursos quando a sala mudar fisicamente.
