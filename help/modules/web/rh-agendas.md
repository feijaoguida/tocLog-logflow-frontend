# Agenda de Salas

## O que esta funcionalidade faz

Organiza reservas de salas com horario, titulo do encontro e sala selecionada.

## Quando usar

- Para reservar uma sala de reuniao.
- Para consultar ocupacao e agenda do dia.
- Para evitar conflito de uso entre equipes.

## Passo a passo de uso

1. Acesse ` /dashboard/rh/agendas `.
2. Escolha a sala desejada.
3. Informe titulo, datas e horarios da reserva.
4. Salve e confirme se o evento entrou na agenda.

## Campos e elementos da tela

| Campo | Explicacao |
| --- | --- |
| Titulo | Nome do compromisso |
| Sala | Espaco reservado |
| Data e hora | Janela da reserva |
| Agenda | Area de consulta dos compromissos existentes |

## Dicas de uso

- Use titulos claros para facilitar leitura coletiva.
- Verifique a agenda antes de reservar horarios concorridos.

## Erros ou duvidas comuns

- `Nao encontro a sala`: validar se ela esta cadastrada e ativa.
- `A reserva conflitou`: revisar horario e disponibilidade do espaco.

## Boas praticas

- Reservar apenas o tempo necessario.
- Cancelar ou ajustar eventos que nao vao acontecer.
