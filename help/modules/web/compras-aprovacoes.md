# Aprovações

## O que esta funcionalidade faz

Agrupa a fila de pedidos aguardando decisao, permitindo aprovar ou reprovar com motivo.

## Quando usar

- Quando o usuario tem responsabilidade de aprovacao.
- Para tratar pendencias do pipeline de compras.
- Para registrar motivo de reprova em casos nao conformes.

## Passo a passo de uso

1. Abra ` /dashboard/compras/aprovacoes `.
2. Revise a lista de solicitacoes pendentes.
3. Entre na acao de aprovar ou reprovar.
4. Informe motivo quando a reprova for necessaria.

## Campos e elementos da tela

| Elemento | Explicacao |
| --- | --- |
| Lista pendente | Solicitações aguardando decisao |
| Aprovacao | Libera o pedido para a etapa seguinte |
| Motivo da reprovacao | Campo obrigatorio quando o pedido for negado |

## Dicas de uso

- Leia justificativa e itens antes de decidir.
- Use reprova com motivo claro para facilitar retrabalho.

## Boas praticas

- Registrar razoes objetivas na reprovacao.
- Priorizar pedidos urgentes com impacto operacional.
