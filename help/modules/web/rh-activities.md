# Atividades

## O que esta funcionalidade faz

Permite registrar atividades diarias, consultar historico proprio e do time, e administrar o catalogo de categorias quando houver permissao.

## Quando usar

- Para registrar o trabalho executado no dia.
- Para gestores acompanharem a equipe.
- Para manter o catalogo de atividades coerente com a operacao.

## Passo a passo de uso

1. Abra ` /dashboard/rh/activities `.
2. Escolha a aba correta: meus registros, time ou catalogo.
3. Informe data, horario, categoria, descricao manual e observacoes.
4. Salve e use editar quando precisar corrigir um registro.

## Campos e elementos da tela

| Campo | Explicacao |
| --- | --- |
| Data, inicio e fim | Janela principal da atividade |
| Categoria | Item do catalogo da filial |
| Descricao manual | Complemento quando a atividade nao estiver coberta |
| Pausas | Permite registrar intervalos por tipo |

## Dicas de uso

- Use a categoria padronizada sempre que ela existir.
- Registre observacoes curtas e objetivas para facilitar auditoria.

## Erros ou duvidas comuns

- `Nao vejo a aba do time`: revisar permissoes e escopo do gestor.
- `A categoria nao aparece`: validar a filial carregada e o catalogo ativo.

## Boas praticas

- Corrigir registros no mesmo dia quando possivel.
- Evitar descricoes vagas quando a atividade tiver impacto operacional.
