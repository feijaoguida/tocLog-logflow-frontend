# Salas Mobile

## O que esta funcionalidade faz

Permite consultar salas e registrar reservas pelo app.

## Quando usar

- Ao reservar sala durante deslocamento.
- Para verificar disponibilidade sem abrir o desktop.

## Passo a passo de uso

1. Abra `Salas`.
2. Escolha o ambiente desejado.
3. Informe titulo, data e horario da reserva.
4. Confirme o agendamento.

## Campos e elementos da tela

| Campo | Explicacao |
| --- | --- |
| Sala | Espaco reservado |
| Titulo | Nome da reuniao |
| Data e horario | Janela da reserva |
