# Pedidos Mobile

## O que esta funcionalidade faz

Abre pedidos simples de compra pelo app do colaborador.

## Quando usar

- Para registrar necessidade rapida em mobilidade.
- Para acompanhar a lista de pedidos enviados pelo celular.

## Passo a passo de uso

1. Abra `Pedidos` na aba `Mais`.
2. Inicie um novo pedido.
3. Informe nome, descricao, quantidade e observacao opcional.
4. Envie e acompanhe a lista local exibida na tela.

## Campos e elementos da tela

| Campo | Explicacao |
| --- | --- |
| Nome / item | Identificacao do pedido |
| Descricao | Detalhe do que precisa ser comprado |
| Quantidade | Volume solicitado |
| Observacao | Contexto opcional |
