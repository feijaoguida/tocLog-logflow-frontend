# Atividades Mobile

## O que esta funcionalidade faz

Permite registrar atividades pelo app do colaborador.

## Quando usar

- Quando o registro precisar ser feito fora do desktop.
- Para informar atividade com descricao e contexto rapido.

## Passo a passo de uso

1. Abra `Atividades` no app.
2. Escolha a atividade cadastrada ou descreva manualmente.
3. Informe observacoes relevantes e confirme o envio.

## Campos e elementos da tela

| Campo | Explicacao |
| --- | --- |
| Atividade | Item da lista principal |
| Descricao manual | Usada quando a lista nao cobre o caso |
| Observacao | Resultado, contexto ou detalhe importante |
