# Feedbacks Mobile

## O que esta funcionalidade faz

Permite ao colaborador abrir e acompanhar feedbacks no app mobile.

O fluxo cobre:

- feedback para empresa
- feedback 1 para 1
- leitura de feedbacks recebidos
- detalhe da thread
- indicacao de quando RH tambem visualiza a conversa

## Quando usar

- Quando o colaborador estiver longe do desktop e precisar registrar um feedback.
- Quando houver necessidade de responder uma thread rapidamente.
- Quando for importante conferir se um 1 para 1 tambem esta sob visibilidade do RH.

## Passo a passo de uso

1. Abra `Mais > Feedbacks`.
2. Revise a lista de threads.
3. Toque em uma thread para ver status e historico.
4. Use `Novo` para abrir o composer.
5. Se o feedback for `1 para 1` ou corporativo, selecione o destinatario da mesma empresa.

## Campos e elementos da tela

| Elemento | Explicacao |
| --- | --- |
| Status | Situação operacional do feedback |
| Label de visibilidade | Indica se o RH tambem acompanha o 1 para 1 |
| Composer | Permite criar feedback real com titulo, destinatario, descricao e regras de privacidade |
| Metadados | Tipo, categoria, leitura e regra de acompanhamento |

## Regras importantes

> [!IMPORTANT]
> No app, o 1 para 1 tambem informa quando RH nao esta visualizando a conversa.
