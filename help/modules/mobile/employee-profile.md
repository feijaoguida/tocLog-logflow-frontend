# Perfil e Mais

## O que esta funcionalidade faz

Concentra o perfil do colaborador e os atalhos secundarios do app, como pedidos e helpdesk.

## Quando usar

- Para revisar dados do proprio perfil.
- Para acessar modulos menos frequentes pela aba `Mais`.

## Passo a passo de uso

1. Abra `Perfil` para revisar seus dados.
2. Entre em `Mais` para acessar atalhos complementares.
3. Navegue para pedidos, helpdesk e demais acessos disponiveis.

## Campos e elementos da tela

| Elemento | Explicacao |
| --- | --- |
| Perfil | Dados principais do colaborador |
| Aba Mais | Menu de acessos secundarios |
| Atalhos | Entradas para pedidos, ajuda e outras funcoes |
