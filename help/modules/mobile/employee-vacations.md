# Férias Mobile

## O que esta funcionalidade faz

Permite consultar e solicitar ferias pelo app do colaborador.

## Quando usar

- Para enviar uma solicitacao sem usar desktop.
- Para acompanhar situacao dos pedidos ja feitos.

## Passo a passo de uso

1. Abra `Ferias` no app.
2. Informe datas desejadas e observacao, se necessario.
3. Envie a solicitacao e acompanhe o status retornado.

## Campos e elementos da tela

| Campo | Explicacao |
| --- | --- |
| Data inicial / final | Periodo pretendido |
| Observacao | Contexto adicional para o gestor ou RH |
| Lista de solicitacoes | Historico visivel no app |
