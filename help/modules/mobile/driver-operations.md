# Operação do Motorista

## O que esta funcionalidade faz

Resume as rotas localizadas do app de motorista encontradas no projeto: home, explore e detalhe de viagem por identificador.

## Quando usar

- Para investigar o que esta disponivel hoje no app de motorista.
- Para acompanhar um detalhe de viagem quando houver rota conhecida.

## Passo a passo de uso

1. Abra o app do motorista.
2. Consulte a home principal.
3. Use a rota de detalhe quando houver identificador de viagem.

## Campos e elementos da tela

| Elemento | Explicacao |
| --- | --- |
| Home | Tela inicial do motorista |
| Explore | Rota auxiliar encontrada na estrutura |
| Viagem por id | Detalhe localizado em `trips/[id]` |
