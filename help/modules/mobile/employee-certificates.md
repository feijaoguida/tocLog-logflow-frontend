# Atestados Mobile

## O que esta funcionalidade faz

Permite enviar atestados e contexto de afastamento direto do app.

## Quando usar

- Quando o colaborador precisa informar um afastamento.
- Quando o documento esta disponivel no celular.

## Passo a passo de uso

1. Abra `Atestados`.
2. Informe periodo e contexto do afastamento.
3. Anexe o documento.
4. Envie o registro.

## Campos e elementos da tela

| Campo | Explicacao |
| --- | --- |
| Periodo | Datas relacionadas ao atestado |
| Contexto | Explica o afastamento |
| Anexo | Documento comprobatório |
