# Prestação de Contas Mobile

## O que esta funcionalidade faz

Registra despesas pelo celular com suporte a anexo de imagem e PDF.

## Quando usar

- Ao registrar gasto em campo.
- Quando o comprovante esta disponivel no proprio aparelho.

## Passo a passo de uso

1. Abra `Prestacao de contas` no app.
2. Informe origem, local, valor e descricao.
3. Anexe imagem ou PDF do comprovante.
4. Envie e acompanhe a lista.

## Campos e elementos da tela

| Campo | Explicacao |
| --- | --- |
| Origem | Tipo da despesa |
| Local | Onde o gasto ocorreu |
| Valor | Quantia informada |
| Anexo | Comprovante em imagem ou PDF |
