# Helpdesk Mobile

## O que esta funcionalidade faz

Permite abrir chamado e acompanhar tickets do colaborador no celular.

## Quando usar

- Ao reportar problema fora do desktop.
- Para acompanhar chamados em andamento.

## Passo a passo de uso

1. Abra `Ajuda` ou `Helpdesk` na aba `Mais`.
2. Consulte a lista dos seus tickets.
3. Abra novo chamado com titulo e descricao.
4. Volte a lista para acompanhar o resultado.

## Campos e elementos da tela

| Campo | Explicacao |
| --- | --- |
| Titulo | Resumo do problema |
| Descricao | Detalhe do incidente |
| Lista de tickets | Historico do colaborador |
