# Imagens da Central de Ajuda

Use esta pasta para armazenar prints reais da ajuda.

## Convencao recomendada

- `usuarios-listagem.png`
- `usuarios-criar.png`
- `assistentes-editar.png`
- `dashboard-visao-geral.png`

## Como referenciar no Markdown

Use o caminho da rota interna de imagens:

```md
![Legenda do print](/api/help-images/usuarios-listagem.png)
```

## Observacoes

- Se o print ainda nao existir, registre um placeholder no Markdown com o nome esperado do arquivo.
- Evite sobrescrever imagens antigas sem validar se a tela mudou de forma relevante.
